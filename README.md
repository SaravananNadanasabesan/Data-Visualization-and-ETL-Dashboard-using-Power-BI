Data Visualization and ETL Dashboard using Power BI
📌 Project Overview

This project was developed as part of the Applied Science and Technology program at Conestoga College over a period of 3 months (February – April 2024).

The objective of the project was to design and develop an interactive Power BI dashboard solution that enables business users to monitor key performance indicators (KPIs), analyze operational trends, and support data-driven decision-making.

The solution focused on:

Integrating data from multiple heterogeneous sources
Performing ETL and data transformation processes
Building a centralized analytical data model
Delivering dynamic and interactive dashboards for business reporting
🎯 Project Goal

The primary goal of the project was to improve reporting efficiency and business visibility by automating manual reporting processes and delivering a centralized analytics dashboard.

The dashboard provides:

KPI tracking
Sales trend analysis
Regional performance monitoring
Category-level insights
Interactive reporting capabilities
🚩 Business Challenge

The organization faced several data and reporting challenges:

Data was distributed across multiple sources with inconsistent formats
Reporting processes were manual and time-consuming
Business stakeholders lacked real-time visibility into operational performance
Data inconsistencies affected reporting accuracy
Existing reports did not support dynamic filtering or detailed analysis

The project aimed to solve these issues by implementing a scalable Power BI reporting solution with automated ETL workflows and standardized reporting logic.
